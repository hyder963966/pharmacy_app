# صيدليتي

تطبيق Flutter لإدارة الصيدلية الذكية بواجهة عربية RTL، تخزين محلي عبر Hive، وبناء Web/PWA جاهز.

## التشغيل

```powershell
flutter pub get
flutter run -d chrome
```

تم بناء نسخة ويب في:

```text
build/web
```

ويمكن تجربتها محلياً من الرابط:

```text
http://localhost:8087
```

## الميزات

- شاشة مخزون بألوان فيروزية وبيضاء وتصميم مسطح.
- بحث باسم الدواء أو الاسم العلمي أو الاستعمالات.
- تصفية أفقية بالشكل الصيدلاني وقائمة للمجموعة العلاجية.
- إضافة وتعديل دواء مع حقول السعر والكمية وحد إعادة الطلب.
- شاشة مسح باركود بالكاميرا مع بديل تصوير العلبة.
- تفاصيل الدواء مع تعديل، حذف، وبيع سريع يخصم من المخزون.
- إشارة كمية حرجة عند الوصول لحد إعادة الطلب.
- تقرير PDF للمخزون مع خط عربي مدمج.
- ضبط تذكير أسبوعي أو شهري يظهر داخل التطبيق عند فتحه.

## ملاحظات تقنية

- تحليل OCR الحقيقي يحتاج لاحقاً ربط ML Kit أو خدمة OCR، والواجهة الحالية تلتقط صورة العلبة وتسمح باختيار اسم مقترح أو تعبئة الحقول.
- إشعارات نظام التشغيل المحلية يمكن إضافتها عبر `flutter_local_notifications` عند تجهيز Android/iOS SDK؛ النسخة الحالية تعرض التنبيهات داخل التطبيق وتحفظ إعداد التذكير محلياً.
